# Nexus Platform

Enterprise collaboration and resource management SaaS designed to showcase full-stack product development.

## Stack

- Java 21 + Spring Boot
- Angular + TypeScript
- PostgreSQL
- Redis
- WebSocket
- JWT / role-based authorization
- Docker Compose
- GitHub Actions

## Product scope

Nexus centralizes internal communication, meeting-room scheduling, people directory and operational dashboards in one application.

## Main features

- Authentication and role-based access control
- Users, teams and departments
- Direct messages and channels
- Real-time updates
- Meeting-room scheduling with conflict detection
- Department-based visibility rules
- Operational dashboard
- Audit log
- Notification layer
- REST API with OpenAPI documentation

## Architecture

```text
nexus-platform/
├── backend/
│   ├── api
│   ├── application
│   ├── domain
│   └── infrastructure
├── frontend/
│   └── Angular application
└── compose.yml
```

## Portfolio goal

This project evolves the Nexus concept into a production-oriented SaaS architecture and demonstrates backend, frontend, authorization, real-time communication and deployment skills.
